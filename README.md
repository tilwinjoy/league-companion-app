# League Companion App

The landing page for **League Companion App** — a lightweight, free to use Windows desktop companion
for League of Legends that tracks your champion and skin collections, mastery progress,
and per-account wishlist sale alerts.

This repository contains the static marketing site only. The desktop application itself
is distributed as a download from the GitHub **Releases** page.

## What the app does

The site showcases the desktop companion's feature set:

- **Collection tracking** — champion and skin inventories with instant filters for
  champion, rarity, tier, and ownership state.
- **Mastery explorer** — every champion's mastery tier, milestone progression, and
  points-to-next-level tracking.
- **Wishlists & sales radar** — pin any skin, chroma, or cosmetic and get real-time
  desktop alerts when it rotates into the weekly store, drops in price, or hits the
  Mythic Shop.
- **Community rankings & spotlights** — embedded SkinSpotlights previews and community
  poll rankings for every cosmetic.
- **Smart loot engine** *(coming soon)* — Hextech crafting intelligence that
  cross-references unowned skin shards with community tier lists.
